# 00631L Lab v9.14 Comparison Default

## Scope

This release makes ETF comparison less surprising.

- The comparison panel now starts with the current ETF only.
- Same-type comparison remains available through the existing quick action.
- Users can still clear the basket and choose 1-5 ETFs manually.

## User Impact

The history/backtest page no longer automatically compares every selected view against 00631L or a preset basket. The default is now a neutral current-ETF view, and comparison becomes an explicit user action.

## Limits

- No new data source was added.
- No investment instruction wording or automated trading behavior was added.
