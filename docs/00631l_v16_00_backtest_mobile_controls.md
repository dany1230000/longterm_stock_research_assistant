# 00631L v16.00 Backtest Mobile Controls

v16.00 makes the phone backtest controls shorter and easier to compare.

## What changed

- Phone width now uses a two-option strategy toggle instead of a taller chip
  wrap.
- The parameter strip is fixed into five compact columns: strategy, initial
  amount, monthly amount, contribution day, and cost.
- The editable amount/cost form stays collapsed behind the existing details
  panel.
- Widget tests guard the compact strategy toggle and parameter strip height.

## Scope

- No backtest formula changes.
- No future-performance claims.
- No data-source changes.
- No transaction instruction wording.
