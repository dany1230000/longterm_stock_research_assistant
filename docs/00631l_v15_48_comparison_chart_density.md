# 00631L v15.48 comparison chart density

## Scope

v15.48 tightens the ETF comparison chart on phone width.

## Changes

- Keeps ETF comparison as a user-selected basket instead of a fixed 00631L baseline.
- Shortens the comparison chart status row on phone width.
- Uses a horizontal legend strip so ETF names do not push the chart downward.
- Hides duplicated compact bottom tick labels on phone width and relies on the clearer start/mid/end date strip.
- Turns chart touch details into a compact date and value row.

## Product Rule

Comparison remains a historical data view. It describes selected ETF history and does not provide trading instructions.
