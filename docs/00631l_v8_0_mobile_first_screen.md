# 00631L lab v8.0 手機首屏整理

v8.0 針對公開 PWA 手機首屏再整理一次，目標是打開後更快看懂狀態，減少重複與等待時的雜訊。

## 完成內容

- 總覽頁移除重複的「今日摘要」卡，只保留「今日快覽」作為首屏資料狀態入口。
- 今日快覽保留內容物、盤中 NAV、歷史、後端四個欄位，並以中文狀態顯示資料來源。
- 內容物不可用時顯示「不可用」，不顯示錯誤快照日期。
- loading shell 移除四張 skeleton 指標卡，改成更短的載入狀態與單一首頁準備卡。
- 近一年走勢仍直接顯示，不折疊。

## 不變範圍

- 不改資料來源與歷史資料計算。
