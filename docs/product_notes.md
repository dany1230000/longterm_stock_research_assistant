# Product Notes

## 目前產品定位

LongTerm Stock Research Assistant 是中長線股票研究助理，協助使用者以財報、營收、估值、趨勢、風險提醒與歷史統計整理研究參考。它不是投顧工具，也不提供方向性結論。

## 已完成功能

- Dashboard：今日研究摘要、觀察清單、估值偏高清單、營收轉強清單、自選股列表。
- Stock Detail：總覽、財務、估值、風險、筆記分段。
- Screener：條件設定、條件摘要、條件篩選結果、空狀態。
- Backtest：策略條件摘要、統計指標、年度報酬表、與 0050 比較。
- Journal：研究日記表單、情緒標籤、記憶體暫存紀錄、空狀態。
- Settings：免責聲明、資料來源、資料授權提醒、版本資訊、未來功能 placeholder。

## 尚未完成功能

- 真實台股行情、財報、營收、ETF 與指數資料。
- 使用者登入與跨裝置同步。
- 永久儲存研究日記。
- 可重現的歷史資料回測引擎。
- AI 摘要 API 串接。
- 視覺回歸測試與行動裝置斷點驗證。

## 不能使用的投資建議文案

新增文案時不得使用交易動作指令、價格承諾、風控價位承諾、收益承諾、明牌式描述或煽動式形容詞。所有個股與策略內容都要以研究參考、觀察清單、條件篩選結果、歷史統計與風險提醒方式呈現。

## 下一階段開發建議

- 定義資料 schema：價格、財報、月營收、股利、ETF、指數與籌碼欄位。
- 將 repository 拆成 mock 與 API-backed implementation。
- 加入研究提醒 placeholder 的互動原型。
- 補充更多 widget tests，涵蓋篩選條件、日記新增與詳情分段切換。
- 建立產品文案檢查腳本，阻擋不合規語氣。

## 未來接真實資料前需要確認的資料授權事項

- 行情資料是否允許在 Web App 中展示。
- 財報與營收資料的來源、延遲時間、更新頻率與再散布限制。
- ETF 與指數資料是否可用於比較圖表。
- 付費資料是否限制商業用途、快取時間或使用者數量。
- AI 摘要是否能使用第三方資料作為輸入，以及是否需要額外揭露資料來源。
