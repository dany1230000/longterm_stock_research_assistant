# 00631L v15.44 history and backtest spacing

## Scope

v15.44 tightens the mobile history/backtest page spacing.

## Changes

- History top strip uses thinner vertical padding on phone width.
- History, data quality, and holdings-history sections use shorter phone gaps.
- Backtest quick result, date controls, and parameter sections use shorter phone gaps.
- Existing date range controls and calculations are unchanged.

## Product Rule

The history/backtest page should open with the selected range, chart context, and backtest quick view close together. Detailed quality and parameter controls remain available without taking over the first screen.
