# 00631L v15.47 settings first screen density

## Scope

v15.47 tightens the mobile settings first screen.

## Changes

- Reduces the gap between the settings summary and account/preference cards.
- Uses tighter quick-summary spacing on phone width.
- Keeps diagnostics, ETF data readiness, deployment, and App Store preparation under advanced settings.
- Preference cards remain two columns on phone width without overflow.

## Product Rule

The settings tab should feel like a normal app settings/account page first. Maintenance and deployment checks stay available, but they should not dominate daily use.
