# 00631L v16.41 History Badge

v16.41 changes the phone history/backtest top-strip badge from `HIS` to `歷`.

## Why

The history tab should read like product UI, not an internal diagnostic panel.
The label `歷` is short enough for phone width and clearly tied to historical
price data.

## Scope

This is a label-only UI change. Date range controls, chart data, backtest
calculations, and ETF selection behavior are unchanged.
