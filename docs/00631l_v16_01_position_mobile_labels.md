# 00631L v16.01 Position Mobile Labels

v16.01 shortens the phone position page labels so the page feels more like an
account panel and less like a long form.

## What changed

- Saved-position input now shows the compact title "修改持倉" on phone width.
- The low-frequency JSON/export/clear area now uses the compact title "工具" on
  phone width.
- Desktop wording keeps the fuller labels.
- Widget tests guard that compact phone wording replaces the longer labels.

## Scope

- No position calculation changes.
- No storage changes; position data remains local-only.
- No advice wording or transaction actions.
