# 00631L v16.44 Overview Source Line

v16.44 reduces first-screen visual noise in the phone overview.

## Changed

- The phone overview data-source row is now one compact status line instead of
  four separate mini cards.
- Daily holdings, intraday NAV, history rows, and frontend mode remain visible.
- The one-year chart stays open on the first screen.

## Scope

This is a layout-only change. It does not change official holdings, live NAV,
static history, ETF search, backtest calculations, or position tracking.
