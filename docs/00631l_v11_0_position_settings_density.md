# 00631L lab v11.0 position and settings density

## Goal

Continue the mobile design pass by reducing repeated secondary details on
pages that should behave like compact app tabs.

## Changes

- Removed the duplicate position source chip row from the position first screen.
- Kept full position source detail inside the existing expandable source panel.
- Narrowed the position save/export/clear action buttons.
- Tightened the settings summary card padding.
- Increased settings preference card aspect ratio so the first screen is less
  vertically heavy.

## Scope

This is a layout-only pass. It does not change local position storage,
calculations, ETF history data, backend operations, or AI analysis behavior.
