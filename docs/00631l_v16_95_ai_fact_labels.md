# 00631L v16.95 AI fact labels

v16.95 makes the AI first-screen fact labels more explicit.

## Changes

- The AI headline facts now use `內容 / 盤中 / 曝險`.
- This replaces the shorter `日 / 盤 / 曝險` wording.
- The labels now describe the data type instead of acting like internal abbreviations.

## Scope

No analysis provider, prompt, data source, or rule-based calculation changed.
This release only updates AI first-screen labels and widget coverage.
