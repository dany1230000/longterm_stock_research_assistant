# 00631L v15.46 AI first screen density

## Scope

v15.46 tightens the mobile AI first screen.

## Changes

- AI hero uses tighter phone padding.
- The phone headline is limited to two lines.
- The primary program action becomes a one-line action row on phone width.
- The daily interpretation card stays visible before advanced AI details.

## Product Rule

AI should read like a concise daily data interpretation. Advanced source details remain available, but the first screen should prioritize today's data state, premium/discount context, holdings context, and program actions.
