# 00631L lab v7.9 首頁資訊密度

v7.9 調整手機首頁的資訊順序，目標是打開公開 PWA 後能更快看懂今日資料狀態。

## 完成內容

- 總覽頁首屏順序改為：行情卡、今日快覽、近一年圖表、內容物摘要、進階資料。
- 「今日快覽」顯示 AI 第一段摘要、內容物日期、盤中 NAV 時間、歷史筆數與後端狀態。
- 內容物不可用時，今日快覽不顯示快照日期，避免把錯誤或 0 值快照看成有效資料。
- 行情卡高度略縮小，手機首屏可看到更多核心資料。
- 原本「更多資料」改名為「進階資料」，把資料品質、比較、模式與維護細節集中在摺疊區。

## 不變範圍

- 不改資料來源與 parser。
- 不改 00631L 以外 ETF 的資料可用性判斷。
- 不新增投資建議、自動交易或通知。
- static public、live proxy、mock fallback 的來源標示維持原本規則。
