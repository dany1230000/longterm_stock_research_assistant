# 00631L v16.80 account settings polish

## Scope

This pass makes the right-bottom account tab feel more like a user settings
page and less like a system diagnostics page.

## Changes

- The compact settings first screen keeps only account, appearance, current ETF,
  local position, and data mode cues.
- Advanced backend and deployment details remain available behind the advanced
  settings panel.
- The former maintenance-diagnostics label is now presented as service and data
  status.
- Phone widget coverage verifies that technical diagnostics stay out of the
  first screen.

## Non-goals

- No data-source behavior changed.
- No TX live data was added.
- No trading instruction or investment guidance was added.
