# 00631L v17.03 symbol search density

v17.03 reduces repeated chips in the phone ETF search sheet.

## Changes

- The compact search status row no longer shows both `可用 N` and
  `歷史 N / M`.
- Phone search keeps the full history denominator and gap count so users can
  still understand data coverage.
- ETF selection and search ranking are unchanged.

## Scope

This release only changes compact search sheet wording. It does not change ETF
catalog loading, stock search, selected ETF switching, history import status, or
comparison logic.
