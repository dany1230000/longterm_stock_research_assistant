# Product Scope v0.2

## 產品定位

中長線股票研究助理 v0.2 是 Web Demo 階段的研究流程工具。它協助使用者用財務、營收、估值、風險、條件篩選、策略研究、ETF 比較、投資組合風險、提醒中心與輔助研究筆記，建立自己的研究流程。

## 本階段範圍

- 使用 Flutter Web。
- 使用 Riverpod、go_router 與 fl_chart。
- 使用本地 mock repository。
- 不接真實 API。
- 不做登入。
- 不做後端。
- 不做付款或訂閱。
- 不新增 Android / iOS / Windows 平台設定。

## v0.2 主要功能

- 研究工作台：整合觀察清單、風險、產業分布與快速入口。
- 個股詳情：分頁式研究資訊與模擬圖表。
- 條件篩選：多條件、排序、preset 管理與研究卡片。
- 策略研究：多個 mock 策略與歷史統計圖表。
- 投資組合：升級為底部主要 Tab，包含持股總覽、集中度、曝險、風險提醒與情境模擬。
- ETF 比較：兩檔 ETF mock 比較與重疊率提醒。
- 提醒中心：次要頁，包含營收、估值、風險、ETF、投資組合與 mock 事件提醒。
- 研究筆記：降級為輔助頁，保留 CRUD、篩選、排序與紀律摘要。

## 非目標

- 不提供個別操作結論。
- 不提供自動交易。
- 不提供即時行情。
- 不處理真實帳號資料。
- 不處理付款或訂閱。

## 文案原則

- 使用研究參考、模擬資料、教育用途、歷史統計與風險提醒語氣。
- 避免方向性、承諾式或煽動式表述。
- 在策略研究、ETF 比較、投資組合風險與個股詳情頁維持明確提醒。
