# Public Demo Feedback Questions

## 使用者類型分類

### 新手

特徵：剛開始建立股票研究習慣，需要清楚的資訊層級與風險提示。

最應該觀察的回饋重點：

- 是否理解這是研究與教育用途工具。
- 是否能分辨模擬資料與真實資料。
- 是否能看懂體質分數、風險提醒與估值分位的含義。
- 是否有任何文案讓人誤以為 App 會給方向性結論。

### 存股族

特徵：重視公司穩定度、殖利率、現金流、產業位置與長期觀察。

最應該觀察的回饋重點：

- 是否能快速看到獲利、安全、現金流與估值狀態。
- 風險提醒是否有助於建立觀察清單。
- 研究日記是否能支援定期檢討。
- 是否需要加入更多股利或資產品質欄位。

### 中長線投資人

特徵：重視基本面、估值、趨勢與風險條件的綜合判讀。

最應該觀察的回饋重點：

- 個股詳情頁的分段是否符合研究順序。
- 財務趨勢與估值區間是否足夠支援初步研究。
- 條件篩選結果是否有助於縮小研究清單。
- 回測頁是否清楚表達歷史統計限制。

### 量化研究者

特徵：重視條件定義、資料欄位、回測假設與可驗證性。

最應該觀察的回饋重點：

- Screener 條件是否明確。
- 回測條件摘要是否足夠可追溯。
- 年度報酬、最大回撤、勝率與比較基準是否清楚。
- 未來接真實資料時是否需要更完整的資料版本紀錄。

## 給早期使用者的 10 個問題

1. 你是否能快速理解這個 App 的定位是研究與教育用途？
2. 你是否能清楚辨識目前資料是模擬資料？
3. Dashboard 的今日研究摘要是否幫助你快速掌握整體狀況？
4. 自選股卡片中的產業、分數、近一年表現與風險標籤是否容易閱讀？
5. 個股詳情頁的總覽、財務、估值、風險、筆記分段是否符合你的研究流程？
6. 財務趨勢圖表與估值區間文字是否容易理解？
7. 風險提醒的嚴重程度與說明是否足夠清楚？
8. 條件篩選頁是否讓你容易建立研究清單？
9. 回測頁是否讓你理解結果只是歷史統計？
10. 研究日記欄位是否能幫助你記錄理由、觀察重點、風險假設與事後檢討？

## 回饋紀錄方式

收集回饋時建議記錄：

- 使用者類型。
- 使用裝置與螢幕尺寸。
- 最容易理解的頁面。
- 最需要改善的頁面。
- 是否有任何文案看起來過度像方向性結論。
- 使用者希望下一版優先補強的資料欄位或研究流程。
