# 00631L v16.40 Overview Stack Density

v16.40 tightens the phone overview market stack so the home screen is easier to
scan immediately after opening the PWA.

## Changed

- The one-year overview chart remains visible and is not folded.
- The compact chart height is reduced slightly.
- The market stack padding and divider gaps are tightened.
- The first-glance holdings chips use less vertical padding.
- Widget tests lower the phone market-stack height guard.

## Scope

This release is layout-only. It does not change live proxy data, static history,
holdings parsing, backtest calculations, AI text generation, or position data.
