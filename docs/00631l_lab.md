## Premium/discount status note

After v1.0, the lab displays a premium/discount status block on `/00631l-lab`. It is a price-deviation hint based on intraday NAV `premiumDiscountPct`, not investment advice.

Classification uses percentage points:

- `null`, `error`, `unavailable`, or `mock`: show intraday data unavailable.
- `stale`: show data may be outdated.
- `abs(premiumDiscountPct) <= 0.20`: normal.
- `0.20 < abs(premiumDiscountPct) <= 0.50`: watch.
- `0.50 < abs(premiumDiscountPct) <= 1.00`: elevated.
- `abs(premiumDiscountPct) > 1.00`: extreme.

Positive values mean the market price is above estimated NAV. Negative values mean the market price is below estimated NAV. If intraday NAV is stale or unavailable, the app should not present a premium/discount judgment as official.

Live/proxy sources:

- Yuanta Basic information: official via backend proxy.
- Yuanta holdings ratio: official daily snapshot via backend proxy.
- TWSE intraday NAV: official via `https://mis.twse.com.tw/stock/data/all_etf.txt`, `sourceContract: twse_a_k_json`.
- Yuanta INAV: official fallback, `sourceContract: yuanta_inav`.
- TX quote: mock/fallback only.

## Intraday NAV contract status - 2026-06-08

The 00631L lab still covers only 00631L.

Intraday NAV now supports two backend source contracts:

- `twse_a_k_json`: TWSE official market-site aggregate feed at `https://mis.twse.com.tw/stock/data/all_etf.txt`. The backend flattens `a1[].msgArray` and selects only `a == "00631L"`.
- `yuanta_inav`: Yuanta official INAV API used by `https://www.yuantaetfs.com/tradeInfo/INav/Asia_ETF`. This is Yuanta's own field contract and is not presented as TWSE a-k JSON.

Set source mode with `${env:00631L_INTRADAY_NAV_SOURCE}`:

- `twse`: TWSE only.
- `yuanta`: Yuanta only.
- `auto`: TWSE first, Yuanta fallback.

If the relevant URL env vars are not set, intraday NAV remains `sourceStatus: unavailable` and the Flutter page keeps its mock/error fallback behavior. Official daily holdings remain daily snapshots; intraday NAV is only for market price, estimated NAV, premium/discount, and data time.

`00631L 正二研究室` 是單一 ETF MVP，只針對元大台灣50正2（00631L）整理研究用資訊，不擴大到全市場正二或所有槓桿 ETF。

## 頁面內容

- 官方基本資訊：基金名稱、追蹤指數、成立日、上市日、是否配息、風險等級、管理費、保管費。
- 官方每日內容物：基金資產總淨值、每單位淨值、發行單位數、股票 / ETF / 債券 / 期貨資產、現金與保證金明細、股票明細、期貨明細。

- TX 台指期觀察：TX 近月價格、契約月份、加權指數、契約價值、期現價差、夜盤變動。
- 基礎分析摘要：只描述曝險、折溢價狀態與資料時效，不提供買賣建議。

## 官方每日資料 vs 盤中估算資料

官方每日內容物是元大投信揭露的每日快照。股票、期貨、現金、保證金與應收應付項目不應被視為盤中即時改變。

盤中只能更新市價、投信預估淨值、預估折溢價、期貨價格與基於這些資料的估算。若即時資料抓不到，頁面會顯示「即時資料暫不可用」，並保留官方每日資料。

## Repository 設計

- `LiveOfficial00631LRepository`：保留 timeout、retry 與外部 fetcher 注入點。Flutter Web 不直接抓官方頁面，避免 CORS 或官方來源不穩定讓整頁失效。

## 更新策略

- 官方每日內容物：設計上每 5 至 10 分鐘檢查一次即可，只有 `tradeDate` 或 `sourceHash` 改變時才視為新快照。
- 即時淨值 / 折溢價：依 TWSE JSON `userDelay`，預設 15000 ms。Live 模式應在 backend/proxy 實作 timeout、retry limit 與 exponential backoff。
- TX 報價：目前只有 repository interface 與 mock/fallback。若官方來源受 CORS 或權限限制，請由 backend/proxy 正規化後注入。

## CORS / Backend Proxy

若 Flutter Web 不能直接抓元大或 TWSE 資料，請新增 backend/proxy：

1. backend 抓官方頁面或官方 JSON。
2. backend 回傳 UTF-8 文字、TWSE JSON 或已正規化 JSON。
3. Flutter 端把 backend URL 注入 `LiveOfficial00631LRepository` 的 fetcher。
4. live 失敗時交給 `Cached00631LRepository` 使用 cache 或 mock fallback，UI 不將 mock 偽裝成 official。

第二輪新增了最小 backend/proxy 準備：

前端預設仍使用 mock。啟用 proxy 需要 compile-time flags：

```powershell
flutter run -d chrome --dart-define=USE_00631L_LIVE_PROXY=true --dart-define=00631L_PROXY_BASE_URL=http://localhost:8000
```

狀態標示：

- `official`: 原始官方狀態，只在 repository 直接標官方時使用。
- `proxy`: 前端經 backend/proxy 取得官方資料。
- `cached`: live 失敗時使用快取。
- `mock`: 安全 fallback，不代表官方資料。
- `error`: live 或 parser 錯誤。
- `stale`: 官方每日內容物超過 1 個交易日未更新。

官方每日內容物是每日快照；盤中可更新的是市價、預估淨值、折溢價與期貨/指數估算。頁面不提供買賣建議。

## v1.2 每日內容物歷史

`/00631l-lab` 現在會在 live proxy 模式讀取 backend 的 holdings history summary，顯示「每日內容物歷史」表格。欄位包含日期、TX 權重、台積電權重、股票資產 %、期貨資產 %、現金與保證金 %、NAV、發行單位數。

history 來源是 Yuanta 00631L ratio official daily snapshot。backend 只在成功抓到 official holdings 時保存，並以 `tradeDate` 去重；沒有 history 時前端顯示「尚無歷史紀錄」。mock/fallback 不會被標示為 official history。

官方每日內容物不是盤中即時內容物。盤中即時資料仍只用於市價、預估淨值、折溢價與資料時間。

## v1.3 內容物變化提醒

`/00631l-lab` 會用最近兩筆 official holdings history 產生「內容物變化提醒」。提醒項目包含 TX 權重、台積電權重、現金與保證金比例、期貨資產比例、股票與期貨合計曝險，以及官方 holdings 是否超過 1 個交易日未更新。

目前門檻：

- TX 權重變化達 5 個百分點。
- 台積電權重變化達 2 個百分點。
- 現金與保證金比例增加達 5 個百分點。
- 期貨資產比例變化達 10 個百分點。
- 股票與期貨合計曝險不在 180%-220% 參考區間。
- 官方 holdings 超過 1 個交易日未更新。

這些提醒只描述資料狀態與內容物比例偏離程度，不構成交易策略或買賣建議。

## v1.4 盤中折溢價歷史
