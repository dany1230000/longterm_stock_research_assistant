# 00631L v6.99 Overview Chart Header

## Scope

This release removes the `HIS` badge from the first-screen one-year chart
header. The chart now starts directly with the user-facing title `近一年走勢`.

## Behavior

- The chart value, date labels, touch detail, and return calculation are
  unchanged.
- Advanced panels still keep compact technical badges where dense status
  context is expected.
- This is a first-screen readability change only.

## Validation

- Widget coverage confirms `HIS` is absent from the initial overview first
  screen while expanded update details remain available.
