# v0.2 Development Report

## v0.2 完成項目

- App Shell：底部導覽整理為研究工作台、條件篩選、策略研究、投資組合、設定。
- 全域 Demo Banner：明確標示目前使用模擬資料，並提供免責聲明入口。
- 研究工作台：新增今日摘要、自選股總覽、觀察清單、估值偏高觀察清單、營收轉強觀察清單、風險升高觀察清單、產業分布、最近研究筆記與快速入口。
- 個股詳情頁：擴充為總覽、財務、估值、營收、籌碼 / 觀察資料、風險、研究筆記。
- 條件篩選：新增 PB、成長分數、估值分數、風險程度、產業篩選與排序條件。
- 條件 preset：支援 local memory 儲存、載入與刪除。
- 策略研究：支援多個 mock 策略切換，包含統計、年度報酬、權益曲線、回撤曲線與事件列表。
- 研究筆記：降級為輔助頁，支援新增、編輯、刪除、依股票篩選、依情緒標籤篩選與日期排序。
- 研究紀律摘要：在輔助筆記頁保留本月紀錄數、最常出現情緒標籤、尚未檢討紀錄數。
- ETF 比較頁：新增 mock ETF 清單、兩檔比較、重疊率提醒、持股與產業曝險。
- 投資組合頁：升級為底部主要 Tab，包含 mock portfolio、持股總覽、持股權重、產業集中度、單一持股集中度、ETF / 個股比例、風險提醒與情境模擬。
- 提醒中心頁：新增 mock `/alerts` 次要頁，包含營收、估值、風險、ETF、投資組合集中度與 mock 事件提醒。
- 資料架構：新增 ETF、Portfolio、Strategy、ScreenerPreset 等 models 與 repository interface。
- 測試：補上 Screener、preset、Journal CRUD、策略切換、ETF 比較、Portfolio risk 與 routing 測試。

- Screener 條件篩選結果。

- 研究筆記與 Screener preset 目前暫存在 local memory。

## 不碰真實資料的原因

- 真實市場資料可能涉及授權、來源限制、更新頻率、延遲標示與再散布條款。
- 在產品定位與合規邊界尚未審定前，先用 mock data 打磨資訊架構與研究流程。
- 目前階段重點是驗證使用者是否理解研究流程，而不是提供即時資料服務。

## 未來接真實資料前需要確認的授權

- 股票行情、收盤價、歷史價格與均線資料授權。
- 財報、月營收、股利、估值與 ETF 持股資料授權。
- 指數與 benchmark 資料授權。
- 資料延遲、資料來源揭露與再散布限制。
- 使用者資料、研究日記與偏好設定的隱私處理規範。

## 投顧風險邊界

- App 僅提供研究參考、條件篩選結果、觀察清單、風險提醒與歷史統計展示。
- App 不提供個別操作結論、價格承諾、收益承諾或自動交易。
- 所有分數、摘要、圖表與篩選結果都必須標示為模擬資料或研究參考。

## 為什麼不提供買賣建議

- 使用者的財務狀況、風險承受度、資金需求與投資期間各不相同。
- 單一模型或分數無法代表完整投資判斷。
- 本產品定位是協助整理研究流程，而不是替使用者做決策。
- 保持研究與教育用途能降低誤解與合規風險。
