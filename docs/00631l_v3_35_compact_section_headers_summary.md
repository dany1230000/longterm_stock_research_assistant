# 00631L lab v3.35 compact section headers summary

Date: 2026-06-13

## Scope

v3.35 improves mobile layout density across feature pages. It does not change data models, repositories, or backend behavior.

## Changes

- Section header cards now use smaller padding and icon treatment.
- Header subtitles are capped to avoid pushing primary content too far down on mobile.
- Header metric chips use tighter vertical spacing.

## User impact

Feature pages such as contents, history/backtest, position, AI, and settings now reach their primary content sooner. The app keeps the dedicated section identity without feeling like every tab starts with an oversized card.

## Boundaries

- No data source changes.
- No change to static-public or live-proxy mode selection.
- No new analysis or trading behavior.
