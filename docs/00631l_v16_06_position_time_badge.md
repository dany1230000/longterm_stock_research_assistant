# 00631L v16.06 Position Time Badge

## Scope

v16.06 makes the phone position page clearer after a local position is entered.
The account strip now shows the quote time beside the local-only badge.

## UI Behavior

- The first position screen still prioritizes market value, unrealized result,
  cost, and position weight.
- The quote time appears as a compact badge, so users can see the estimate time
  without opening source details.
- Export and clear actions remain in the tools panel.

## Data Scope

No position calculation changed. Position data remains local-only and is not
uploaded by the app.
