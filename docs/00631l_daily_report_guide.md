# 00631L daily report guide

This guide explains how to read the local Markdown report generated by the 00631L daily cycle.

## Where Reports Live

Run:

```cmd
scripts\00631l_daily_cycle.cmd
```

or regenerate the report from current local state:

```cmd
scripts\00631l_generate_daily_report.cmd
```

Reports are written to ignored local storage:

```text
backend\reports\
```

The latest metadata file is:

```text
backend\reports\00631l_daily_report_latest.json
```

These files are local operational output and should not be committed.

## What To Check First

Start with:

- `overallStatus`
- `warnings`
- `failures`
- holdings trade date
- intraday NAV data time
- source status

`PASS` means the local checks completed without warnings. `WARN` means the data or environment needs review but the report was generated. `FAIL` means at least one required check failed.

## WARN Review

Common acceptable WARN cases:

- intraday NAV freshness outside regular market hours
- local `.env` missing while mock/fallback mode remains usable
- intraday URL not configured in a local script run
- no backup yet on a fresh setup
- backup manifest records that an optional source file did not exist

For WARN, read the warning text and compare it with the data time. Do not treat WARN as official data freshness.

## FAIL Review

For FAIL:

1. Read `errorMessage`, `failures`, and the failed step name.
2. Run the specific script again if needed, for example:

```cmd
scripts\00631l_check_integrity.cmd
scripts\00631l_restore_dry_run.cmd
py backend\scripts\smoke_00631l_live.py
```

3. Check `docs\00631l_troubleshooting.md` for local startup, backend, CSV, history, and intraday NAV issues.

Do not delete tests or local history to hide a FAIL.

## Holdings Section

The holdings portion summarizes the latest official Yuanta ratio snapshot saved locally:

- trade date
- NAV per unit
- fund net asset value
- outstanding units
- stock/futures/cash structure
- TX and TSMC weights when present in the official snapshot

Yuanta holdings are daily official snapshots. They are not intraday holdings.

## Intraday NAV Section

The intraday NAV portion summarizes market price, estimated NAV, premium/discount, data date, data time, and source contract.

Intraday NAV is a live or cached estimate source. It does not change the official daily holdings snapshot.

## Source Status

- `official`: fetched and parsed from the official source.
- `cached`: served from local cache or saved local state.
- `mock`: local fallback data, not official.
- `fallback`: secondary configured source.
- `stale`: data may be old; check data time.
- `error`: fetch, parse, or local read failed.
- `unavailable`: source is not configured or no local state exists.

Mock/fallback data must not be treated as official.

## Scope Boundary

The report is an operational data-status report. It describes data freshness, source status, holdings history, exports, backups, and local script results.

It does not connect TX live, does not expand beyond 00631L, does not send notifications, and does not provide investment guidance.
