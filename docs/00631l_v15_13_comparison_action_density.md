# 00631L v15.13 comparison action density

## Scope

This release tightens the ETF comparison action row on phone-width screens.

## Changes

- Phone layout now uses shorter comparison action labels:
  - `清空`
  - `同類型`
  - `目前`
- Wider layouts keep the full labels:
  - `清空組合`
  - `套用同類型`
  - `只看目前 ETF`
- The selected ETF basket behavior is unchanged. Users can still clear the
  basket, apply the same-type preset, or return to the current ETF only.

## Non-goals

- No new ETF data source.
- No TX live integration.
- No trading guidance.
