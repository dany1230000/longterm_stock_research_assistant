# 00631L v16.43 Remaining Data Badges

v16.43 finishes the visible data-badge cleanup started in v16.42.

## Changed

- Remaining `DAY` badges now display `日`.
- Remaining `LIVE` badges now display `盤`.
- Remaining `HIS` badges now display `歷`.
- `TX`, `2330`, and `AI` remain as-is because they identify the market item,
  holding, or analysis source clearly.

## Scope

This is a presentation-only change. It does not change data fetching, holdings
history, intraday NAV, price history, backtest calculations, or position
tracking.
