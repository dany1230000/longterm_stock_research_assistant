# 00631L v15.77 Date Toolbar Density

## Scope

v15.77 tightens the phone date range controls used in the history/backtest
section.

## Changes

- Phone date buttons now render as one-line controls instead of two-line cards.
- The date range panel uses shorter padding and a smaller `日期` badge.
- Widget coverage now guards that phone date controls stay at toolbar height.

## Notes

- No history data, split-adjusted price handling, or backtest calculation
  behavior changed.
- This is a layout polish release for mobile readability.
