# 00631L lab v10.2 AI first-screen bullets

Release tag: `00631l-lab-v10.2-ai-first-screen-bullets`

## Goal

Make the `AI 分析` page feel like it is actually explaining today's data before
the user opens detail panels.

## Changes

- The first screen now shows `今日重點` with the first two rule-based analysis
  bullets.
- The existing conclusion, daily facts, and program action remain above the
  detailed AI panels.
- Matrices, full diagnostics, complete data summaries, and additional action
  items remain behind the existing detail sections.

## Boundaries

- The analysis source remains `rule_based`.
- No external LLM key or service was added.
- No investment guidance, notification, broker login, or automated action was
  added.
