# 00631L v15.43 overview daily summary card

## Scope

v15.43 merges the mobile overview AI line and holdings digest into one daily summary card.

## Changes

- The overview first screen now uses one compact daily summary card after the quote/chart stack.
- The card keeps the AI short line and the official holdings digest together.

## Product Rule

The overview should answer the first-screen question quickly:

- current quote and one-year chart
- today's data interpretation
- official holdings context

Detailed controls stay in their own tabs.
