# 00631L v16.45 Holdings Wording

v16.45 removes debug-style wording from visible holdings and data-health
surfaces.

## Changed

- `source` is shown as `來源`.
- `tradeDate` is shown as `日期`.
- Missing TX or 2330 values display `不可用`.
- Data-health text describes the Yuanta daily ratio snapshot in Chinese.

## Scope

This is a wording-only change. It does not change official holdings parsing,
history storage, price history, live NAV, backtest calculations, or position
tracking.
