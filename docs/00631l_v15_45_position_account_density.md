# 00631L v15.45 position account density

## Scope

v15.45 tightens the mobile position page.

## Changes

- Removes the extra top gap before the account summary when a local position exists.
- Uses tighter phone padding in the account summary card.
- Reduces metric tile spacing on phone width.
- Keeps local-only storage, JSON export, clear action, and estimate calculations unchanged.

## Product Rule

The position page should feel like an account snapshot first. Detailed local data tools remain available, but low-frequency controls should not dominate the first screen.
