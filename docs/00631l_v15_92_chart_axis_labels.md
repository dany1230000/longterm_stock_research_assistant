# 00631L v15.92 Chart Axis Labels

## Scope

This release improves chart date readability on compact screens.

## Changes

- Shared history and comparison chart date labels now use 起 / 中 / 迄.
- The shorter captions leave more room for the actual dates on phones.
- Chart touch detail still shows the selected date and value.
- No historical data, split-adjustment, backtest, or source-status logic
  changed.

## Validation

- Widget coverage verifies the new date-axis labels and existing touch-detail
  date/value fields.
- Full release validation remains required before tagging this release.
