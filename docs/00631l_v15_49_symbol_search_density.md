# 00631L v15.49 symbol search density

## Scope

v15.49 tightens the left-top ETF search sheet on phone width.

## Changes

- Shortens the search sheet header and current ETF card on phone width.
- Keeps the main status row focused on filter, result count, and ready history count.
- Moves maintenance-style data gap details to the database status expansion.
- Keeps result rows compact while preserving the expandable data detail panel.

## Product Rule

The search sheet should feel like a symbol picker first. Data maintenance status remains available, but it should not dominate the first search screen.
