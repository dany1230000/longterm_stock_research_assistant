# 00631L lab v3.37 overview metric grid summary

Completed: 2026-06-13

## Scope

v3.37 improves the mobile overview first screen by replacing the horizontal
"today at a glance" metric strip with a responsive metric grid.

## Changes

- Shows official holdings date, intraday NAV, holdings focus, historical
  coverage, and historical performance in a compact grid.
- Uses two columns on phone widths, three columns on medium widths, and five
  columns on wide screens.
- Keeps secondary chart, exposure, and maintenance details below expandable
  panels.

## Data Meaning

- Official holdings remain daily snapshots.
- Intraday NAV and premium/discount depend on backend live data.
- Historical performance is backward-looking only.

This page remains a data-status and research tool. It is not investment advice.
