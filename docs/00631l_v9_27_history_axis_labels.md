# 00631L lab v9.27 history axis labels

v9.27 improves the history/backtest chart axis labels for phone reading.

## What changed

- The history chart date strip now uses `起點`, `中段`, and `終點` instead of
  shorter single-character labels.
- The existing one-year default range and custom date controls remain unchanged.
- The chart touch detail still shows the selected date and value separately.

## Scope

This is a UI clarity update only. It does not change data sources, backtest
math, ETF scope, or live TX behavior.
