# 00631L v6.44 holdings digest grid fit

v6.44 makes the official holdings digest fit phone width.

## What changed

- The overview holdings digest now uses a fixed three-cell row.
- The three cells are TX futures, TSMC stock, and stock/futures/cash mix.
- The mix title is shortened to `股 / 期 / 現金`.
- Long percentage values scale down inside the tile instead of pushing the third tile off screen.

## Data rules

- These values come from the official daily holdings snapshot.
- They are not intraday holdings.
- Intraday state remains the NAV / premium-discount data path.
