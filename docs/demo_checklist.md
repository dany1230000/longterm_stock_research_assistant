# Demo Checklist

## Demo 啟動方式

```bash
flutter pub get
flutter run -d chrome
```

若要先確認 release build：

```bash
flutter build web
```

## Demo 展示流程

1. 開啟首頁，說明這是 Web MVP Demo，且目前使用模擬資料。
2. 介紹 Dashboard 的今日研究摘要、觀察清單、估值偏高清單與營收轉強清單。
3. 點進 `2330 台積電` 個股詳情頁，展示總覽、財務、估值、風險與筆記分段。
4. 切到條件篩選頁，調整條件並展示條件篩選結果。
5. 切到回測頁，說明歷史統計結果與 0050 比較。
6. 切到研究日記頁，新增一筆研究紀錄。
7. 切到設定頁，說明資料來源、免責聲明、授權提醒與未來功能 placeholder。

## 建議展示順序

Dashboard → 個股詳情 → Screener → Backtest → 研究日記 → Settings。

## 目前是 Mock Data 的功能

- 自選股清單與股票基本資料。
- 財務趨勢、EPS、ROE、毛利率與營收 YoY。
- 估值區間、PE / PB 分位數與殖利率。
- 風險提醒與 AI 摘要文字。
- 條件篩選結果。
- 策略回測統計與年度報酬表。
- 研究日記資料暫存於 memory repository。

## 未來會接真實資料的功能

- 台股行情與價格資料。
- 財報、月營收、股利與估值資料。
- ETF 與指數比較資料。
- 研究提醒與資料更新時間。
- AI 摘要所需的資料輸入。

## 展示注意事項

- 不可宣稱這是投資建議。
- 不可宣稱模擬資料代表真實市場結果。
- 不可宣稱回測代表未來績效。
- Demo 版本只展示研究工作流、資料分層與互動體驗。
